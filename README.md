# Hybrid Watermarking and Fingerprinting for LLM Attribution
This project evaluates a hybrid approach for identifying the source and provenance of text generated by large language models (LLMs).
The system combines:
1. **KGW-style statistical watermarking** for detecting whether text contains an embedded watermark.
2. **Cross-model behavioral fingerprinting** for estimating which candidate language model generated the text.
3. **Soft probabilistic decision fusion** to combine watermark and fingerprint signals.
4. **Robustness evaluation** under text transformations and attack scenarios.
The implementation evaluates multiple open-source causal language models and reports watermark detection, model attribution, hybrid classification, perplexity, and generation latency metrics.

## Evaluated Models
The default experiment evaluates the following models:
```text
gpt2
distilgpt2
facebook/opt-125m
EleutherAI/gpt-neo-125M
Qwen/Qwen2.5-0.5B-Instruct
mistralai/Mistral-7B-Instruct-v0.2
```
Additional compatible Hugging Face causal language models can be added to the `MODELS` list.

## Robustness Attacks
The pipeline evaluates attribution performance after applying several text transformations:
| Attack | Description |
|---|---|
| `none` | No modification |
| `sentence_reorder` | Randomly reorders sentences |
| `truncate` | Retains approximately 70% of the original words |
| `summarize` | Retains approximately 50% of the original words using a naive truncation baseline |
| `noise` | Replaces approximately 10% of words with `[MASK]` |
> Note: `sentence_reorder` is a sentence-order transformation, not semantic paraphrasing. True paraphrase attacks are reserved for future work.

## Experimental Configuration
The default configuration is:
```python
SEED = 42
NUM_SAMPLES = 60
BATCH_SIZE = 10
MAX_NEW_TOKENS = 128
GENERATION_TEMPERATURE = 0.7
FP_TEMPERATURE = 0.05
```
Each model produces:
```text
60 samples
× 2 generation conditions
× 5 attack conditions
= 600 evaluation rows per model
```
With six models, the complete experiment produces approximately 3,600 rows.

## Metrics
The experiment reports the following metrics.
### Watermark Metrics
- Watermark detection rate.
- Mean watermark z-score.
- One-sided p-value.
- TPR at fixed false-positive rates.
- AUROC for watermark detection.

### Fingerprinting Metrics
- Fingerprint score.
- Top-1 model attribution accuracy.
- Cosine similarity to candidate galleries.
- Confusion matrix across candidate models.

### Hybrid Metrics
- Hybrid detection rate.
- Fused score.
- Hybrid AUROC.
- TPR at fixed false-positive rates.

### Model Performance Metrics
- Perplexity.
- Generation latency in milliseconds per sample.

## Usage
The main implementation is provided as a Jupyter notebook:
```text
KGW_WM_Probe_FP.ipynb
```
Run the notebook sequentially to:
1. Install dependencies.
2. Load the required libraries.
3. Define the watermarking and detection classes.
4. Build behavioral galleries for all candidate models.
5. Generate watermarked and control text.
6. Apply robustness transformations.
7. Calculate watermark, fingerprint, hybrid, perplexity, and latency metrics.
8. Export the results.
The main output files are:
```text
output/galleries.npz
output/all_results.csv
results/results_<model_name>.jsonl
```
Model names containing `/` are converted to `_` when used in output filenames.

## For reproducible results, keep the following fixed:
- Model versions.
- Tokenizers.
- Watermark key.
- Watermark parameters.
- Probe prompts.
- Generation parameters.
- Random seed.
- Candidate model list.
Because generation uses sampling and different hardware backends may produce small numerical differences, exact bit-level reproducibility is not guaranteed in every environment.

## Limitations
This project is an experimental evaluation and has several limitations:
- The watermark uses a simplified context-hash green-list construction.
- The attack called `summarize` is a naive truncation baseline rather than a semantic summarization model.
- Sentence reordering does not perform paraphrasing.
- Behavioral fingerprint galleries are built from only a small number of probe prompts.
- Fingerprint probabilities depend on the selected candidate-model set.
- The hybrid threshold is currently manually selected.
- Results may vary with model versions, decoding parameters, hardware, and prompt selection.
- Perplexity values are not directly comparable across models with different tokenizers.
- The current implementation loads models sequentially and may require substantial GPU memory and execution time.

## Future Work
Potential improvements include:
- Adding true semantic paraphrasing attacks.
- Evaluating translation and back-translation attacks.
- Testing token deletion, insertion, and substitution attacks.
- Calibrating the fusion threshold on a validation set.
- Learning an optimized fusion model instead of using a fixed soft-OR rule.
- Expanding the probe-prompt gallery.
- Evaluating larger and instruction-tuned models.
- Reporting confidence intervals over multiple random seeds.
- Measuring quality degradation caused by watermarking.
- Comparing against additional watermarking methods.
- Adding ROC, precision-recall, and calibration plots.
- Packaging the implementation as a reusable Python library.
